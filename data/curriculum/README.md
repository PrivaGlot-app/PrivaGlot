# 你的教材（data/curriculum）

这里是你自己的教材，**永不进仓库，也永不被更新覆盖**。

- 日常创建和维护请在网页里点「📖 我的教材 · 创建一本」：拍课本 → AI 提取 →
  粘贴 → 保存，全程不用碰 JSON，保存后立即可选，无需重启。
- 也可以手工把教材 JSON 文件放进这里（一本教材一个文件，格式见
  `docs/教材规范.md`），放完重启服务，或在网页控制台调
  `POST /api/curriculum/reload` 重扫。
- 名字以 `_` 开头的文件和目录会被跳过。
- 教材的唯一标识是文件里的 `id`，改文件名不影响学生的练习记录。
