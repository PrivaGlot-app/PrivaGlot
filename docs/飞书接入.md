# 飞书接入指南

学生手机上装一个飞书 App，跟机器人单聊上课：选学生 → 点「上课」→
语音/文字对话 → 下课自动出报告和 AI 进度评估。**交互与网页版同一套逻辑**：
老师只在显式开课后才说话，学生档案由你显式创建或点选，没有自动建档。
本文管**部署后的交互与排障**；怎么买到服务器、怎么部署升级，见
[README](../README.md)。

**不需要域名、不需要 HTTPS、不需要 ICP 备案**：机器人通过飞书的
WebSocket 长连接收事件，服务端零公网入站端口，境内/境外 VPS 均可运行。

## 一、创建飞书应用

### 方式 A（推荐）：部署时授权链接确认，自动创建

跑飞书形态的部署流程（VPS 用 README 里的一键命令）——脚本发现还没有
飞书凭据时，会打印一条飞书授权链接：

1. 把链接复制到手机浏览器打开；
2. 在手机上点一次「确认创建」。

完成。应用由飞书自动创建（名称预填「PrivaGlot AI 外教」），机器人能力、
消息收发 / 语音与图片资源等权限、WebSocket 长连接事件订阅全部按官方
智能体应用模板预置好，
App ID / App Secret 由脚本自动写进 `.env`——**全程不需要打开飞书开放
平台，也没有任何复制粘贴**。

- **授权前提**：你的飞书账号名下要有**自己创建**的企业，**别用公司号**。
  纯个人账号部署会"成功"但机器人永远触达不了你；部署脚本会自动探测，
  命中时现场指引创建企业（免费 1 分钟）并重新给出授权链接。完整说明见
  README「授权前提」。
- 预置权限是官方模板（约 36 项），为本项目所需权限的超集；创建即生效。
- 国际版 Lark 组织同样可用：脚本会自动识别并写好 `FEISHU_DOMAIN`。
- 授权超时或被拒绝时，退回方式 B，或直接重跑一次部署命令。

### 方式 B（备用）：手动创建（约 10 分钟，人工操作）

适用：授权流程走不通、或需要模板之外的权限/配置时。

1. 打开 [飞书开放平台](https://open.feishu.cn/)，用手机号注册/登录；
   按提示创建一个**企业自建应用**（组织免费创建，你就是管理员）。
2. 应用详情页「凭证与基础信息」里拿到 **App ID**（`cli_` 开头）和
   **App Secret**，部署脚本提示时粘贴（或手工写进 `.env`）。
3. 左侧「应用能力 → 添加应用能力」，开启**机器人**。
4. 左侧「权限管理」，搜索并开通以下权限：
   - `im:message`（获取与发送单聊、群组消息）
   - `im:message:send_as_bot`（以应用的身份发消息）
   - `im:resource`（读取与上传消息中的资源文件——语音下载、语音与
     图片上传都靠它）
5. 左侧「事件与回调」：
   - 订阅方式选择 **「使用长连接接收事件」**（不要选回调地址——这正是
     免域名免备案的关键）；
   - 添加事件：**接收消息 `im.message.receive_v1`**。
6. 「版本管理与发布」创建一个版本并发布。自建应用由你自己的组织管理员
   （就是你）审核，通常几分钟内可用。

## 二、配置服务端

`.env` 里追加（模板见 `.env.example`）：

```ini
FEISHU_APP_ID=cli_xxxxxxxx
FEISHU_APP_SECRET=xxxxxxxx
```

可选键：`FEISHU_DOMAIN`（海外 Lark 填 `https://open.larksuite.com`）、
`FEISHU_SESSION_IDLE_TIMEOUT`（会话空闲秒数，超时先自动下课再开新课，
默认 7200）。部署形态三选一（Windows 双击 / VPS 一键 / 源码运行）全部
见 README——只有**源码运行**才需要自己装 Python 3.11+、ffmpeg 和
`pip install -r requirements.txt`（已含 lark-oapi）。

先自检，再启动（源码运行形态手动执行；VPS 一键形态由部署脚本在启动后
自动做 60 秒自检、不稳自动回滚，无需手动跑命令）：

```bash
python run_feishu.py --selftest   # ffmpeg / 飞书连接 / 凭据 / 联网 / opus 转码
python run_feishu.py              # 启动机器人（前台常驻；配合 systemd 守护）
```

网页版（`python run.py`）可以继续同时用：两者共享 `data/` 里的学生档案与
教材。**同一个学生同时在两边上课会被拒绝**（后到的开课方收到人话提示）——
先在另一边「下课」再继续。

## 三、聊天里能做什么

接入分两种人，别混：

- **部署者（你）**：部署时授权的人。应用就创建在你自己的组织里，
  你是所有者，授权完即可直接和机器人单聊。
- **其他使用者（如孩子的家长用他们自己的手机）**：自建应用只对组织内
  成员可见——他们的飞书账号**必须先被邀请进你的组织**（成员管理 →
  邀请成员，免费版够用），然后才能搜到机器人、发起单聊。

想验证：拿一个没被邀请的飞书账号搜机器人——搜不到；邀请进组织后立刻
能搜到。

### 学生侧（发语音/文字给机器人）

| 指令 | 作用 |
|---|---|
| 上课 | 从上次练的单元继续；第一次上课只有一本教材时直接开，多本打开选课主页挑，没有教材则引导创建 |
| 上课 序号 / 序号-单元 | 指定教材开课，如 `上课 1`、`上课 1-2` |
| 选课 | 打开**选课主页**（聊天里的主页，网页端选课页的等价）：按教材分组列出单元与进度，点单元即开课 |
| 自由对话 | 切到自由聊天模式（脱离教材）；结束同样出小结和「接下来？」卡 |
| 下课 | 结束本次课：词汇报告 → AI 进度评估 → 报告卡 |
| 进度 | 当前学生的各单元进度百分比 |
| 学生 / 切换 学生名 | 打开**学生选择卡**或切换当前学生（「绑定 学生名」同样可用） |
| 新建学生 姓名[,年龄[,兴趣]] | 建档并设为当前学生，如 `新建学生 周一鸣,9,dogs`；语言背景默认中文（`语言:海外华人家庭` 可指定）；无参数递**建档表单卡** |
| 选老师 / 设老师 老师id / 设风格 风格 | 网页端「高级设置」的等价：换老师会重置风格为该老师默认；选择被记住，下次开课沿用 |
| 直接发语音 / 文字 | **课中**=口语输入，老师照常回复（打字练习）。**没有进行中的课不会召唤老师**——只会得到引导；隔夜挂着的课（默认空闲 2 小时）先自动结算出报告 |

开课成功后会收到**课中控制卡**（含「⏹ 下课」），课模式下还会收到
**🎯 本课目标卡**（目标词汇的开课快照）。

首次联系机器人（发文字或语音）会收到**学生选择卡**——和网页端首屏一样
先选学生：点选已有档案，或「➕ 新建学生」走建档表单卡。选好学生后自动
落到**选课主页**。

### 卡片：不用背关键词

机器人会在**合适的时机主动递上带按钮的卡片**，点了就等于发对应指令
（底层翻译成同一条指令通道，文字回复永远照常可用）：

- **学生选择卡**：首次联系随欢迎语收到，发「学生」随时找回。点学生名
  切换当前学生；档案超过 9 位时发「切换 学生名」。卡底恒定两个入口：
  **「📞 联系开发者」**（直跳开发者名片）和**「🔄 检查更新」**。
- **选课主页**：聊天里的主页 = 网页端选课页的等价。建档/切换学生成功后
  **自动跟上**，发「选课」「面板」「主页」随时找回。单元按钮带进度、
  点开即上课；功能键：📖 管理教材、💬 自由对话、👩‍🏫 选老师、👤 换学生，
  以及 📞 联系开发者、🔄 检查更新。
- **课中控制卡**：开课成功后自动收到，含「⏹ 下课」「📈 进度」
  「👥 切换学生」——课中发「面板」也回这张卡。
- **回复卡**：老师每轮回复是一条语音为主的卡片（>55s 自动分段成多段
  音频），下面挂一个默认收起的「🔊 听不懂？点此查看原文」折叠面板装
  文字全文；语音链路异常时自动回退纯文字，原文不丢。
- **下课「接下来？」卡**：每次下课（含自由对话结束）在报告后附
  再来一课 / 选课 / 自由对话 / 查看进度 / 切换学生。
- **选老师卡**：点老师切换（✓ 标当前），再点风格微调；选择被记住。
- **确认 / 跳过 / 重贴卡**：教材管理里需要确认的操作（保存、删除、解析
  采用等）都附按钮。
- **Key 引导卡**：发「换Key」（不带参数）或还没配 Key 时收到——Key 在
  卡片输入框里提交，**不会留在聊天记录里**，先真实验证再生效、无需重启。
  卡片正文是「怎么拿到 Key」的完整引导（注册链接、防坑说明），与网页端
  同一套文案。
- **✅ 已更新卡**：升级（或回滚）完成后机器人重启，自动推给部署者。

卡片按钮的点击回调走同一条长连接（订阅方式选了「使用长连接接收事件」
即可用，无需配置回调地址）。按钮始终是可选加速：所有功能用文字指令都能完成。

### 管理面（状态 / 换Key / 教材管理，全员开放）

**没有管理员概念**：应用场景只有学生本人与家庭成员（如家长用自己手机
登录），`状态`、`换Key`、`教材管理` 对所有人开放。部署完成后，机器人会
主动给授权部署的人发一张开机欢迎卡。

- **状态**：一屏体检卡（版本 / Key / ffmpeg / 教材数 / 学生档案数 / 绑定数）。
- **换Key sk-xxxx**：先真实验证再生效（内存 + `.env` 同步），无需重启。
- **教材管理**：聊天里建教材/加单元/改单元/改书名/删单元/删教材/看教材
  ——分步向导、逐条回显确认、保存前校验（与网页端同一套规则，校验不过
  不落盘）。**课中还开着时进不去**，先下课。

**教材管理菜单卡**：进入管理模式只收到这一张卡——书单在卡内，全部操作
按钮化，不用背指令格式。向导进行中再点任何菜单按钮会先自动取消上一步，
指令不会被当成内容吃掉；保存/落盘后重新递上这张卡，退出管理回到主页卡。

**改单元是覆盖式编辑**：修改单元的 标题/词汇/句式/语法 时，机器人先回显
当前内容，你发送**完整的新内容整段替换**——要保留的原内容也要包含在内
（加一条=多发，删一条=少发）；清空则发「清空」。校验不过会告诉你原因并
让你原地重发。内置示例教材**只读**（可以看，不可修改删除）。

**看教材三层链**：发「看教材」→ 书选择器卡（每书一按钮）→ 点书出**书内
单元选择器卡** → 点单元出**「📄 单元内容」全文卡**（词汇/句式/语法）。
文字协议 `看单元 书序号`、`看内容 书序号 单元序号` 始终可用；目录为空或
条目过多时自动回落文字清单。

**创建教材 = 拍课本 → AI 提取 → 粘贴**：向导的词汇步骤是一张**一键粘贴卡**
——点「📋 拿提示词」复制提取提示词，发给任意 AI（豆包 / Kimi / ChatGPT）
整理课本页；点「🖼 获取图文说明」看分步图解（也可在向导任意步骤直接发
「图文说明」/「操作说明」）；把 AI 的整段回复粘进卡片提交，自动识别
`[词汇]` / `[句式]` / `[语法]` 三段，解析后确认采用（可「🔄 重贴」）。
手打多行内容则点输入框全屏后发送。词汇请**打字**（英文语音识别不可靠），
支持逗号/顿号/换行分隔，词组（如 short hair）不受影响。

**课中实时词汇命中反馈**（网页端"说对一个词徽章立刻+1"）**仅网页有，
飞书有意不做**：聊天流里逐词发卡会刷屏。飞书只做开课时的目标快照卡 +
下课报告里的命中汇总，信息不丢。

### 机器人菜单（可选，不影响任何功能）

飞书开放平台支持给机器人配菜单，但菜单项与 `application.bot.menu_v6`
事件**只能在开放平台后台手动配置**（没有开放 API）。想用的话：
「应用功能 → 机器人 → 菜单配置」里添加菜单项（类型选事件，`event_key`
直接填指令文字，如 `进度`、`教材管理`），并在「事件与回调」里订阅
`application.bot.menu_v6`。通道会把菜单点击翻译成对应文字指令。
**不配置菜单时所有功能照常可用**，所有功能用文字指令都能完成。

## 四、常见问题

- **授权创建的应用，机器人没反应**：先跑 `python run_feishu.py --selftest`；
  自检通过但收不到消息时，按方式 B 第 6 步到开放平台确认应用是否需要补一个
  版本发布，以及事件订阅里是否有 `im.message.receive_v1`（授权模板正常会带）。
- **发语音没反应**：先跑 `--selftest`；确认长连接订阅方式选对了、事件已加、
  版本已发布。服务重启后飞书会自动重连，不需要重开应用版本。
- **只有文字回复、没有语音**：确认开通了 `im:resource` 和
  `im:message:send_as_bot`（语音上传走 `im:resource`）。
- **家长搜不到机器人**：自建应用只对组织内成员可见，其他使用者必须先被
  邀请进组织（见第三节开头）。
- **同一学生在网页和飞书同时开课**：会被拒绝并提示，先在另一边「下课」。
- **海外用 Lark**：`.env` 里把 `FEISHU_DOMAIN=https://open.larksuite.com`。
- **手工改了学生档案/教材文件**：网页端改动即时生效；手工改文件后重启
  `run_feishu.py`（课程目录启动时扫描一次）。
- **飞书端建的/改的教材，网页端看不到**：教材列表在各进程启动时载入，
  飞书端保存后网页端要**重启**才可见（反之亦然）。重启另一边即可同步，
  属设计内行为、不是故障。

## 五、隐私提示（请如实告知家长）

走飞书通道意味着**孩子的语音和对话文字会额外经过飞书（字节跳动）的服务器**，
同时语音识别、大模型回复与语音合成都由小米 MiMo 云端完成。数据不经过项目
作者的任何服务器；服务端不落盘任何学生语音原文：语音即用即弃，档案里只
保留 ASR 出的文字。完整的数据清单见 README「数据与隐私」——若家长不接受
飞书中转，请使用网页版（浏览器直连你自己的服务器）。
