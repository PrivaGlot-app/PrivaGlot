# 教材格式与创建指南

PrivaGlot **不自带教材库**——每个孩子的课本都不一样，全国十几个出版社、十二年、
上下册，谁也收不全，收全了别人也用不上。所以教材由你自己创建。

好消息是这件事比看上去简单得多：一本书的核心只有**三样东西**——这个单元的
**词汇**、**句式**、**语法**。一个单元花十几分钟就能做好，做一次就能一直用。

---

## 一、推荐方式：网页里点「📖 我的教材 · 创建一本」

不需要懂 JSON，不需要命令行，不需要重启服务：

1. **拍照**：用手机拍下课本的一个单元（或几页）。
2. **让 AI 提取**：把照片发给任意 AI（豆包 / Kimi / ChatGPT 都行），附上
   页面上的「提取提示词」（一键复制）。AI 会把内容整理成
   `[词汇]` / `[句式]` / `[语法]` 三段。
3. **粘贴**：回到网页，把 AI 的回复粘进「从 AI 提取结果粘贴」框，点
   「解析填入」——三个栏目自动填好，检查一下、随手改改都行。
4. **保存**：填好教材名称，点「💾 保存教材」。有问题页面会用中文告诉你
   （比如混进了中文、词汇重复），改好再存。保存后立刻出现在选课页上。

词汇是唯一必填的栏目；句式、语法有就填，没有留空也能上课。

**编辑和删除**：选课页上每本自建教材的标题行有 ✏️ / 🗑️ 按钮。编辑会原样保留
教材身份（id）和每个单元的身份（unit_id），所以改名字、增删单元、调整单元
顺序都不会弄丢孩子的练习进度；捆绑的示例教材只读，不能编辑删除。删除教材
只删文件，进度记录仍保留在档案里（重新放入同 id 的教材文件会自动恢复）。

## 二、教材是什么样子（想手工创建或好奇再看）

一本教材 = 一个 JSON 文件，放在 `data/curriculum/` 里：

```json
{
  "format": "privaglot-textbook/1",
  "id": "my-kid-english-4a",
  "title": "我孩子的英语 四年级上册",
  "units": [
    {
      "unit_id": "unit_1",
      "title": "Unit 1 Helping at home",
      "vocabulary": ["doctor", "nurse", "sweep the floor"],
      "patterns": [
        "What's your mother's job? - She's a doctor.",
        "Can you help? - Yes, I can."
      ],
      "grammar": [
        "Modal verb 'can' (Subject + can + base verb; e.g., 'I can cook.')"
      ]
    }
  ]
}
```

网页生成器会自动填好 `format` / `id` / `unit_id`，你只需要关心
`title` 和三个内容列表。手工创建时：

| 字段 | 说明 |
|---|---|
| `format` | 固定写 `"privaglot-textbook/1"` |
| `id` | 这本书的唯一标识：字母、数字、点、下划线、连字符。**定下来不要改**——学生的练习记录以它为键；文件名倒是可以随便改 |
| `title` | 选课页上显示的名字 |
| `units` | 单元数组，至少一个，数组顺序就是上课顺序 |

单元里 `vocabulary` 必填且非空；`patterns`、`grammar` 可以为空。
三条内容规则（系统保存时会自动检查，不用背）：

1. **只写英文**——不要中文翻译、不要注释，混进中文会被读出来
2. 数组内**不要有重复项**——`vocabulary` 决定课后的词汇覆盖报告
3. 不要空行、空字符串

## 三、检查

手工改过 JSON 之后：

```bash
python setup/check_curriculum.py                 # 扫内置 + 用户两个教材目录
python setup/check_curriculum.py 我的教材.json    # 检查单个文件
```

它会报出：JSON 解析失败（含"像是被截断了"）、缺字段、词汇表为空、混进中文、
重复项、`id` / `unit_id` 重复。**每做完一本就跑一遍**，比上课时才发现问题强得多。

## 四、放在哪里

| 目录 | 放什么 |
|---|---|
| `data/curriculum/` | **你的教材**。永不入库、永不被更新覆盖，日常都在这里 |
| `app/bundled_curriculum/` | 随应用分发的示例教材和模板，程序更新时整体覆盖，别往这里放自己的东西 |

- 名字以 `_` 开头的文件和目录会被整个跳过
- 放进去之后**重启服务**才会出现在选课页（网页里保存的不用，立即可见）
