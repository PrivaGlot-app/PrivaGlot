# 随应用分发的教材（Bundled curriculum）

这个目录里的东西随项目一起分发，**程序更新时会被整体覆盖**。
它是引擎的内部素材，用户不需要（也不应该）往这里放东西。

- `renjiao-pep-4a.json` —— 最小示例教材（人教版四年级上册的 Unit 1）。让你装好
  就能立刻上一节课，同时作为格式的参考样本。
- `_template.json` —— 空白模板。名字以 `_` 开头，不会出现在选课页上。

**创建自己的教材请用网页里的「📖 我的教材 · 创建一本」**，教材会保存到
`data/curriculum/`，永不被更新覆盖。手工创建的格式说明见 `docs/教材规范.md`。
和内置示例同名（id 相同）时，用户教材优先。
